⚡캐치조상훈! - 나만의 상훈 콜렉션 ⚡

본 문서는 앞으로 게임을 유지보수하고 업데이트할 차기 관리자를 위한 「캐치조상훈 운영·관리 매뉴얼」입니다.
기본적인 HTML/CSS/JavaScript 문법을 이해할 수 있다면 누구나 무리 없이 수정·확장할 수 있도록 게임의 구조와 작업 절차를 정리했습니다.
본 문서에는 여느 인터넷 괴담들과 같은 이상한 수칙따위 없습니다. 만약 발견된다면 즉시 "조상훈호잇"을 세 번 외치십시오.

⚠️ 주의 사항
코드를 크게 수정하거나 대량으로 카드를 추가하기 전에는 반드시 프로젝트 폴더를 통째로 복사해 백업해 두세요(또는 Git 커밋).
쉼표 하나만 빠져도 JS 전체가 멈출 수 있습니다.

### ✨프로젝트 개요 및 실행 방법✨ ###

[ 캐치조상훈! ] 은 다양한 종류의 상훈을 모아 콜렉션을 완성하는
본격 초상권파괴 수집형턴제오픈월드액션RPG자동사냥타워디펜스로그라이크비주얼노벨미소녀연애시뮬레이션입니다.

게임 특징
   - 1 / 5 / 10연속 소환(가챠)을 통해 카드를 수집해 도감을 채울 수 있습니다.
   - 서버나 데이터베이스 없이 브라우저만으로 동작하며, 현재 구조상 새로고침 시 도감 진행도는 초기화됩니다.
   - 본 게임의 레이아웃은 PC 브라우저 전체화면을 기준으로 제작되었습니다. 주소창이나 북마크 바로 인해 UI가 깨질 수 있으니, F11을 눌러 전체화면으로 이용해주시길 바랍니다.

실행 방법
   - index.html 을 더블클릭해 바로 실행할 수 있습니다.

### 📖전체 폴더 및 파일 구조📖 ###

파일을 역할별로 분리해 두었기 때문에, 수정하고 싶은 내용이 있을 때 해당 파일만 열어서 고치면 됩니다.


catch_sanghoon/
├── index.html          # 화면 레이아웃과 CSS/JS 불러오기 순서 정의
├── css/
│   └── style.css        # 모든 디자인, 카드 등급별 스타일, 애니메이션 효과
├── js/
│   ├── config.js        # ★ 핵심 설정 파일 (경로, 확률, 시간, 사운드, 특수 이벤트)
│   ├── characters.js   # ★ 카드 도감 데이터 (이름, 등급, 이미지, 전용 사운드)
│   ├── audio.js         # 사운드 재생 엔진 (보통은 수정할 필요 없음)
│   ├── cutscene.js     # 포탈, 이상현상, 합체/엔딩 컷신 연출 엔진
│   └── main.js          # 도감 생성, 뽑기 로직, 해금 판정, 확대 모달, 관리자 모드
└── assets/
    ├── images/           # 모든 카드 이미지 (.JPG, .gif)
    └── audio/             # 모든 효과음 및 BGM (.mp3)


⚠️ 주의 사항 (index.html 스크립트 순서) 
index.html 상단에서 JS 파일을 불러오는 순서는 서로 의존성이 있으므로 절대 순서를 바꾸면 안 됩니다.
( 1. config.js → 2. characters.js → 3. audio.js → 4. cutscene.js → 5. main.js )

### 🎮인게임 기능 및 시스템 설명🎮 ###

코드를 수정하기 전에, 현재 게임이 어떤 흐름과 규칙으로 돌아가는지 먼저 파악해 두면 좋습니다.

① 소환(가챠) 시스템
   - 단일 / 5연속 / 10연속 소환을 지원하며, 10연속 소환에만 '확률 UP'이 적용됩니다.
   - 10연속 포탈(차원 균열) 예고: 10연속 소환 시작 시, 결과에 포함된 카드의 최고 등급에 따라 포탈 색상이 미리 변합니다.
     · SSR 포함 (5.5초): 화이트 → 골드(2초) → 퍼플(3.5초)
     · SR 포함  (4.2초): 화이트 → 골드(2초)
     · R/C만 존재 (2.5초): 화이트 유지
   - 등급별 연출 차이: 5/10연속에서 C, R 등급은 빠르게 뒤집히고(fast-flip), SR, SSR 등급은 카드가 크게 강조되며 화면 플래시·흔들림 효과가 나옵니다.
   - NEW! 배지: 도감에 없는 카드를 처음 뽑았을 때 카드 우측 상단에 빨간 NEW! 배지가 붙습니다. (한 번의 10연속 뽑기에서 같은 신규 카드가 2장 이상 나오면 첫 번째 카드에만 붙습니다.)
   - 연출 스킵(>>): 5/10연속 소환 중 우측 상단 버튼으로 포탈과 카드 뒤집기를 즉시 건너뛸 수 있습니다. (스킵해도 도감 해금은 정상 반영됩니다.)

② 도감 및 카드 확대 보기
   - 정렬 순서: 기본적으로 SSR → SR → R → C → UR 순이며, 같은 등급 안에서는 ID 오름차순으로 정렬됩니다.
   - 툴팁 정보: 도감 카드에 마우스를 올리면 '도감 번호'와 '고유 ID'를 확인할 수 있습니다. (미해금 카드는 ? 또는 ???로 표시)
   - 카드 확대(Zoom): 소환 결과에서 이미 뒤집힌 카드나 도감에서 해금된 카드를 클릭하면 중앙에 크게 확대되어 조상훈 선생님의 다채로운 용안을 감상할 수 있습니다.
   - 긴 이름 자동 축소: 카드 이름이 길어도 카드 밖으로 삐져나가지 않도록 글자 수에 따라 폰트 크기가 자동으로 줄어듭니다.

③ 특수 이벤트 3종 및 발동 규칙
   1. 도감 내 이상현상 (WARNING):
      도감을 70장 이상 모으면 경고창이 2번 점멸하며 비프음이 울립니다. 이후 보유 숫자 색상이 붉게 하이라이트되고, 도감 맨 밑에 숨어 있던 UR 카드(???)가 도감 첫 번째 칸으로 이동합니다.
   2. 봉인 해제 합체 (고대정령 상훈디아):
      일반 뽑기에서는 나오지 않는 R등급 파츠 5종(머리/왼팔/왼다리/오른팔/오른다리, ID 71~75)을 모두 모으면 5파츠가 화면 사방에서 날아와 합체하는 컷신과 함께 상훈디아(ID 26)가 해금됩니다.
   3. 최종 엔딩 (THE ORIGIN 조상훈):
      UR을 제외한 모든 일반 카드를 전부 모으면 모든 카드가 중앙으로 빨려 들어가는 연출 후 UR 카드(ID 999)가 해금되며 엔딩을 맞이합니다.
   - 이벤트 진행 규칙:
     · 5/10연속 소환 도중 조건이 달성되면, 결과창에서 '결과 닫기 X' 버튼을 누른 직후 이벤트가 시작됩니다.
     · 여러 이벤트가 동시에 겹치면 충돌 방지를 위해 [상훈디아 합체 → 최종 엔딩 → 이상현상] 순서로 차례대로 실행됩니다.
     · 합체/엔딩 컷신에서 카드가 3초 동안 완전히 뒤집혀 앞면이 공개된 이후에야 "화면을 클릭하여 닫기"가 활성화됩니다.

### 📚신규 카드 추가 방법 (등급별 가이드)📚 ###

신규 카드를 추가할 때는 기본적으로 다음 2단계만 거치면 됩니다.

   1. 이미지 파일(필요시 사운드 파일)을 assets/images/ (및 assets/audio/) 폴더에 넣는다.
   2. js/characters.js 배열에 카드 정보 1줄을 추가한다.

⚠️ 신규 카드 추가 시 공통 주의사항 
- id는 절대 중복되면 안 됩니다. (26-11-24 기준 일반 카드는 1~81번, 히든 엔딩 카드는 999번을 사용 중이므로 신규 카드는 82번부터 순서대로 붙이는 것을 추천합니다.)
- 파일명의 대소문자까지 정확히 일치시키길 권장합니다. 윈도우에서는 card.jpg와 card.JPG가 같아 보여도, GitHub Pages 같은 웹 서버에서는 대소문자가 다르면 이미지가 깨집니다.
- 도감 총 개수(81 등)와 엔딩 조건은 grade !== 'UR'인 카드 수를 자동으로 계산하므로 따로 숫자를 고칠 필요가 없습니다.

① C / R 등급 카드 추가 (일반 등급)
별도의 사운드 설정 없이도 등급 기본 효과음(CandR.mp3)이 자동으로 적용됩니다.
5/10연속 소환 시 빠르게 뒤집히는 연출(fast-flip)이 적용됩니다.

// js/characters.js의 해당 등급 구역에 추가
{ id: 82, name: "새로운 C상훈", grade: "C", img: "new_c.JPG" },
{ id: 83, name: "새로운 R상훈", grade: "R", img: "new_r.JPG" },

② SR 등급 카드 추가 (희귀 등급)
기본 효과음(SR.mp3)과 함께 금색 테두리, 화면 플래시 및 흔들림 연출이 자동 적용됩니다.
특정 SR 카드에 전용 사운드를 넣고 싶다면 아래 SSR 방식처럼 sound, soundVolume을 적어주면 됩니다.

// js/characters.js의 해당 등급 구역에 추가
{ id: 84, name: "새로운 SR상훈", grade: "SR", img: "new_sr.JPG" },

③ SSR 등급 카드 추가 (최고 뽑기 등급)
SSR 카드는 카드마다 "고유 등장 사운드(sound)와 볼륨(soundVolume: 0.0~1.0)" 을 지정할 수 있습니다.

// js/characters.js의 해당 등급 구역에 추가
{
    id: 85,
    name: "새로운 SSR상훈",
    grade: "SSR",
    img: "new_ssr.JPG",
    sound: "new_ssr.mp3",   // assets/audio/ 폴더 안의 파일명
    soundVolume: 0.8        // 0.0(무음) ~ 1.0(최대)
},

④ UR 등급 카드 (히든/엔딩 전용)
UR 등급은 기본적으로 excludeFromGacha: true로 뽑기에서 제외되며, 도감 맨 마지막에 ???로 나타납니다. 카드가 70개 이상 해금될 시 이상현상 이펙트와 함께 도감 맨 앞으로 이동하고(이벤트 발생 조건은 '인게임 설정 및 세부 요소 조정 방법 ④' 참고), 모든 일반 카드를 모았을 때 엔딩 이벤트와 함께 해금됩니다.

💡 만약 뽑기에서는 나오지 않고 특수 이벤트로만 해금되는 카드를 추가로 만들거나(예: id: 26 고대정령 상훈디아) UR 등급 관련 기믹을 수정하고자 한다면, 이벤트 구성부터 기존 아키텍쳐 전체와의 충돌 여부까지, 고려해야 할 게 상당히 많을 겁니다. 따라서 골치아픈 일이 생기지 않도록 AI의 도움을 받는 쪽을 추천합니다. 이 경우, 프롬프트를 구체적으로 작성하지 않으면 프로젝트 전체가 망가질 수 있으므로 각별한 유의 바랍니다.

### ⚙️인게임 설정 및 세부 요소 조정 방법⚙️ ###

대부분의 게임 밸런스와 타이밍은 js/config.js 한 파일에서 관리합니다.

① 소환(가챠) 확률 조정
js/config.js 의 gachaRates 를 수정하면 됩니다.

gachaRates: {
    normal: { SSR: 0.5, SR: 5.5, R: 45.5 }, // 단일 소환, 5연속 소환
    chanceUp10: { SSR: 1, SR: 10, R: 60 }   // 10연속 소환
},

⚠️ 확률 계산 방식 (중요!)
개별 확률이 아니라 "앞 등급 확률을 계속 더한 누적 확률(%)" 로 입력해야 합니다.
- 공식: { SSR: A, SR: A+B, R: A+B+C }
          (C 등급 확률은 자동으로 100 - (A+B+C))
- 예시: SSR 2%, SR 8%, R 50%, C 40%로 바꾸려면 → { SSR: 2, SR: 10, R: 60 }

⚠️ 주의 사항
확률이 0%보다 큰 등급에는 뽑기 가능한 카드(excludeFromGacha가 없는 카드)가 최소 1장 이상 있어야 합니다.


② 연출 속도 및 대기 시간 조정
js/config.js 의 timings 를 수정하면 됩니다. 단위는 모두 "밀리초(ms, 1000 = 1초)"입니다.

- portalTickMs / portalTicks: 10연속 소환 포탈 지속 시간 (틱 수 × 100ms = 총 대기 시간)
- singleDelay: 단일 소환 시 카드가 확대된 후 뒤집히기 전까지의 긴장감 대기 시간
- multiDelay: 5/10연속 소환 시 카드가 뒤집히기 전 대기 시간 (fast는 C/R, normal은 SR/SSR)
- revealPostDelay: 카드가 뒤집힌 뒤 플래시/흔들림이 나오기 전 대기 시간
- viewTime: 카드 공개 후 다음 카드로 넘어가기 전 감상 시간
- endingTriggerDelay / glitchDelay: 소환 종료 후 엔딩 또는 이상현상이 발동되기까지 대기 시간

③ 사운드 파일 및 볼륨 조정 
js/config.js 의 audio 를 수정하면 됩니다. 혹은 js/characters.js 를 수정하면 됩니다.

- 공통 효과음 변경: js/config.js의 audio 항목에서 파일명(file)과 볼륨(volume)을 수정합니다.
   - beep: 이상현상 경고 비프음
   - urIntro / urFlip: 최종 엔딩 인트로 / 카드 뒤집힘 사운드
   - exodiaPart: 파츠 합체 시 파츠별 등장 사운드
   - defaultGradeSounds: SR, R, C 등급의 기본 효과음 (UR은 전용 음원 urIntro/urFlip 사용)

- 개별 SSR 카드 사운드 변경: js/characters.js에서 해당 카드의 sound, soundVolume 값을 수정합니다.

④ 특수 이벤트 조건 및 파츠 설정
js/config.js 의 events 를 수정하면 됩니다.

- 이상현상 경고 발동 조건 (glitchThreshold): 기본값은 70입니다. 도감을 이 숫자 이상 채우면 경고창과 함께 UR 카드가 도감 최상단으로 이동합니다.
- 합체 이벤트 (exodia):
   - rewardCardId: 합체 결과로 해금될 카드의 id (기본값 26)
   - orderedPartIds: 합체에 필요한 파츠 id 배열 겸 등장 순서 ([71, 75, 73, 72, 74])
   - partLayouts: 각 파츠가 화면 바깥 어디서 출발해(startOffset) 중앙 어디에 모일지(targetOffset) 좌표 계산
- 최종 엔딩 카드의 ID (urEndingCardId): 기본값은 999입니다.

⑤ UI 디자인, 색상, 문구 수정
css/style.css 와 index.html 를 아래에 따라 수정하면 됩니다. index.html 의 경우, 마우스 우클릭 → 연결 프로그램 → 메모장(또는 VS Code)으로도 수정이 가능합니다.

### 🛠️관리자(테스트) 모드 사용법🛠️ ###

게임 테스트나 이벤트 확인을 위해 숫자 0 키로 관리자 모드를 열 수 있습니다. (소환 연출 중이나 엔딩 진행 중에는 작동하지 않습니다.)

입력 가능한 명령어(대소문자 구분 없음)
   - ALL: UR 카드를 제외한 모든 카드 일괄 해금 (최종 엔딩 테스트용)
   - C, R, SR, SSR: 입력한 등급의 카드만 일괄 해금 (R 입력 시 상훈디아 합체 테스트 가능)
   - 숫자 (예: 1, 15): 현재 도감의 해당 번째 칸에 있는 카드 1장 해금 (카드 번호와 카드 ID는 서로 다를 수 있습니다. 도감 카드에 마우스를 올리면 툴팁으로 번호와 ID를 확인할 수 있습니다.)

(※ 부스 운영 시 잠그는 법은 아래 '축제/행사 부스 운영 가이드 ③' 참고)

### 🚑자주 겪는 문제 해결 (FAQ)🚑 ###

Q1. 카드를 추가하고 저장했는데 게임 화면이 아예 먹통이 됐어요(버튼이 안 눌려요).
   → js/characters.js 또는 js/config.js를 수정하다가 쉼표(,), 따옴표(", '), 중괄호(}) 중 하나를 빼먹었을 확률이 99%입니다.
   → F12 → Console 탭을 열어 빨간 줄에 표시된 파일명과 줄 번호를 확인하세요. (SyntaxError)

Q2. 파일을 수정하고 새로고침(F5) 했는데 예전 화면 그대로 나와요.
   → 브라우저가 옛날 파일을 기억(캐시)하고 있어서 그렇습니다. Ctrl + Shift + R(강력 새로고침)을 누르세요.

Q3. 이미지나 사운드가 안 나오고 콘솔에 404 / ERR_FILE_NOT_FOUND가 떠요.
   → 파일이 assets/images/ 또는 assets/audio/ 폴더 안에 정확히 있는지 확인하세요.
   → 파일명 철자 및 확장자 대소문자(.jpg vs .JPG)가 characters.js / config.js와 한 글자라도 다르면 못 불러올 수 있습니다.

Q4. 소리가 살짝 밀리거나 웹 서버로 실행하라는 말을 들었어요.
   → 게임 자체는 index.html 더블클릭(file://)으로도 실행되지만, 브라우저 보안 정책 때문에 고성능 오디오 엔진(Web Audio API)은 웹 서버 환경에서만 작동합니다.
   → 완벽한 사운드 싱크가 필요하다면 VS Code의 'Live Server' 확장 프로그램으로 실행하거나 GitHub Pages에 올려 실행하세요.

Q5. 조상훈 선생님이 인건비를 안줘요.
   → 조상훈 선생님의 지갑을 훔치십시오. 존엄성은 쟁취하는 겁니다.

### ✅업데이트 후 점검 체크리스트✅ ###

코드를 수정하거나 카드를 추가한 뒤에는 브라우저에서 F12(개발자 도구) → Console(콘솔) 탭을 열어둔 상태로 아래 항목을 확인하세요.

1. 콘솔에 빨간색 오류(404 Not Found, SyntaxError 등)가 없는가?
   - 404가 뜬다면 assets/images/ 또는 assets/audio/ 안의 파일명(확장자·대소문자 포함)이 characters.js나 config.js의 철자와 다른 것입니다.
2. 도감 우측 상단 총 개수(0/XX)가 의도한 개수와 일치하는가?
3. 단일 / 5연속 / 10연속 소환 및 연출 스킵이 정상 동작하는가?
4. 신규 추가한 카드가 도감에서 클릭했을 때 정상적으로 확대되고 사운드가 재생되는가?
5. 관리자 기능으로 R 해금(상훈디아 합체) 및 ALL 해금(최종 엔딩)이 끝까지 정상 진행되는가?

### 🎪축제/행사 부스 운영 가이드🎪 ###

본 게임은 웹 배포용이 아닌 학교 축제 및 행사 부스 현장 운영에 최적화되어 있습니다.
행사 당일 원활한 진행을 위해 아래 현장 세팅 및 운영 수칙을 참고하세요.

① 행사 시작 전 PC 세팅 체크
   - 오프라인 실행 가능: 인터넷(Wi-Fi)이 끊겨도 폴더만 있으면 정상 작동합니다.
     (사운드 싱크까지 완벽히 맞추고 싶다면 인터넷 없이도 VS Code의 Live Server 같은 로컬 서버로 띄워두면 좋습니다.)
   - 전체화면(F11) 권장: 브라우저 주소창이나 북마크 바 때문에 화면 아래가 잘리지 않도록 F11 키를 눌러 전체화면으로 실행하세요.
   - 화면 비율 맞춤: 노트북 해상도나 윈도우 배율(125%, 150% 등) 때문에 카드가 너무 크거나 짤려 보인다면, 브라우저에서 Ctrl + '-' / '+' 키로 배율(예: 90%)을 조절하세요.
   - 사전 사운드 테스트: 부스 오픈 전 운영진이 먼저 1회 소환해 보고 스피커 연결 상태와 볼륨이 적당한지 확인해 두세요.

② 현장 참가자 회전 및 리셋 방법
   - 다음 참가자 전환: F5(새로고침)를 한 번 누르면 도감이 0장으로 깔끔하게 초기화됩니다.
   - 진행 중 중단 시: 5/10연속 소환 도중이나 엔딩 중에 참가자가 자리를 떠나도 F5만 누르면 즉시 초기 화면으로 돌아갑니다.

③ 참가자 돌발 행동 방지 수칙
   - 부스 체험 중 누군가 장난삼아 숫자 0 키를 눌러 관리자 모드를 열거나, F12(개발자 도구)를 열어볼 수 있습니다.
   - [권장] 키보드는 관리자가 직접 감독하거나, 담당자에게 해당 내용을 잘 일러두세요.
   - 노트북 키보드가 그대로 노출되는 환경이라면, 행사 시작 전 js/config.js 맨 아래의 adminKey 값을 반드시 null로 바꿔 관리자 모드를 잠그고 운영하세요.
     (adminKey: null)

④ 부스 회전율 및 경품 관련 팁
   - 대기 줄이 너무 길다면 js/config.js의 timings 대기 시간을 조금 줄여 진행 속도를 빠르게 만들 수 있습니다.
   - 경품 이벤트를 연계할 경우, 행사 전에 js/config.js의 gachaRates 확률이 실제 준비한 경품 수량에 맞는지 테스트해 보고 조절하세요.
   - 확률이 기본값인 경우에는 81장을 모두 모아 엔딩을 보기 어려우므로, 구경용 시연 PC나 스태프 시연이 필요할 때만 관리자 모드(0 키 → R 또는 ALL)를 활용하는 것을 추천합니다.
